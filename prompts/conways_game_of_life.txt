Write a single-file Python program using tkinter that implements Conway's Game of Life on a 60x40 grid. The user can click cells to toggle them alive/dead, and drag to paint. Include Start/Stop button, Step button, Clear button, and a speed slider. Color cells based on their age (generations alive) using a heat map from blue (newborn) to red (old). Show generation count and population count. Include preset patterns accessible via a dropdown: Glider, Glider Gun, Pulsar, Spaceship.
